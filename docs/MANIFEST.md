## Rebuild order

Computed from each step's declared inputs: a step runs only after everything it reads exists. This is the
sequence a reader follows to rebuild `out/` from the store, and it is checked on every build - a step that
reads a file nothing earlier produces fails this script rather than producing a plausible-looking order.

1. `bash scripts/fetch_tk2025.sh` — raw workbook downloads into data/raw/ (gitignored)
2. `scripts/ingest_tk2025.py`
3. `scripts/ingest_tk2025_post.py`
4. `scripts/extract_gifts.py`
5. `scripts/redact_outputs.py`
6. `scripts/extract_spending.py`
7. `scripts/extract_neveninstellingen.py`
8. `scripts/build_seats.py` — serialises the curated seat table; seats.json is the curated source, not a product of this step
9. `src/aerarium/cli.py `aer grade``
10. `scripts/gift_timing.py`
11. `scripts/govrun.py`
12. `scripts/thinktanks.py`
13. `scripts/classify_creditors.py`
14. `scripts/donor_claims.py`
15. `scripts/flow.py`
16. `scripts/overshoots.py`
17. `scripts/classify_rekenkamer.py --titles`
18. `scripts/export_view.py (first pass)` — pass one exists because classify_donors reads this file
19. `scripts/classify_donors.py`
20. `scripts/export_view.py (second pass)` — the derivation has to land in the payload, so the export runs twice
21. `scripts/build_state_payload.py`
22. `scripts/reembed_view.py` — injects both payloads into out/index.html
23. `scripts/check_page_renders.py` — executes the page's script against the embedded payload under node
24. `scripts/build_manifest.py` — this file
25. `scripts/verify_bindings.py` — binds prose to artifacts; must exit 0, then --canary must trip

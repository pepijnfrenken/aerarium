# Documentation index

What each document is, and which ones are load-bearing. Everything here is a dated artifact: a finding states
what the data showed on its vintage, a probe states what a source returned, an audit states what an adversarial
reader found. Later corrections live in the documents they correct, not in a changelog.

## Conventions

- **One change, one commit**, and the commit message states what the number now is.
- **A figure carries source, vintage, licence, URL and retrieval date**, down to the Kamerstuk number or the API
  field.
- **Absence is a finding.** "Not published" is not "not paid", and neither is zero.
- **No inferred motive.** The register records a transaction, not a reason.
- **No named person or company as foreign- or extremist-linked** unless a cited authority said it first.
- **Privacy beats completeness**: donor street addresses and places of residence are never published, and the
  unrestricted donor file stays out of the repository.
